# Public Catalog of Hitomi Schemas
This repository hosts a collection of Hitomi schemas for common domain-specific formats. 

[What is a Hitomi schema?](https://github.com/Verticalysis/Hitomi/wiki/Work-with-Domain%E2%80%90specific-Formats)

## List of Schemas
### Log
* [Logcat](log/logcat.yaml) - Log from Android `logcat` command
* [RFC-5424](log/rfc5424.yaml) - RFC-5424 syslog

### Miscellaneous
* [EdgeHistory](edge_history.yaml) - Browser history exported from Microsoft Edge
